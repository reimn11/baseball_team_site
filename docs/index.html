Honolulu Gragons & Makiki Excelsior’s Team Stats

⚾︎Table Explanation⚾︎

game: Number of games you played　（出場試合数）

AB: At-bats （打席数）

HIT: Total hits　（安打）

AVG: Batting Average: HIT/AB　（打率　＝　安打/打席数）

RBI: Runs batted in （打点）

Single: Total 1B （単打）

Doubles: Total 2B　（二塁打）

Triple: Total 3B　（三塁打）

HR: Home runs　（ホームラン）

BB: Walks （四球）

HBP: Hit by pitch　（死球）

SF: Sacrifice flies　（犠牲フライ）

TB: Total Bases = 1×Single + 2×Double + 3×Triple + 4×HR　（塁打 ＝ 1×単打 + 2×二塁打 + 3×三塁打 + 4×ホームラン）

SLG: Slugging percentage = TB / AB.　（長打率　＝　塁打/打席数）

OBP: On-base percentage = (HIT + BB + HBP) / (AB + BB + HBP + SF).（出塁率　＝　(安打数 + 四球数 + 死球数) ÷ (打数 + 四球数 + 死球数 + 犠飛数)）

OPS: On-base percentage + slugging = OBP + SLG.　（OPS ＝　出塁率　＋　長打率）　

“Players highlighted are qualified players (met the minimum AB).”

※ハイライトされている選手は、規定打席（または規定打数）に到達しています。
